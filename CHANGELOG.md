# Changelog

All notable changes to SmoothThai are recorded here.

## 0.1.2

- Add Minecraft 26.3 support for Fabric and NeoForge.
- Bundle Caxton 1.2.0-alpha.3 for Minecraft 26.3.
- Restructure the repository into one self-contained build per Minecraft version.
- Move shared Java sources and resources to `shared/`.
- Resolve Caxton from Modrinth Maven instead of committing jars.
- Add build, verification, documentation, and CI tooling.

## 0.1.1

- Document the Iris/shader font-rendering known issue.
- Bump the release version.

## 0.1.0

- Initial release for Minecraft 1.20.1 (Fabric, Forge) and 1.21.1 (Fabric, NeoForge).
- Bundle Noto Sans Thai and Caxton.
